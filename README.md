# Bharatam Vinyas – Mobile Apps

Public downloads of the Android apps for Bharatam Vinyas products.

## Rule

**One folder per product. APKs live inside the product folder** (never in the repo root).
Each product folder has its own `README.md` (what it is, version, SHA256, install steps) and a `SHA256SUMS` file.
